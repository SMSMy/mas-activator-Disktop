## 📋 وصف البرنامج

**MAS Activator** هو تطبيق سطح مكتب مبني بتقنية **Tauri + Rust** يوفر واجهة عربية احترافية لتفعيل منتجات Microsoft باستخدام نصوص [Microsoft Activation Scripts (MAS)](https://massgrave.dev) الرسمية.

البرنامج يتواصل مع النظام مباشرةً وينفذ عمليات التفعيل الحقيقية — وليس واجهة فقط، بل أداة تشخيص وتفعيل تعتمد مبدأ **النتيجة الصادقة**: لا يُعلن نجاحًا إلا بعد التحقق الفعلي من حالة الترخيص بعد كل عملية.

## 🚀 التثبيت والتشغيل

### النسخة المحمولة (موصى بها — الاستخدام المتوقع لمرة واحدة)
1. حمّل `MAS.Activator_x.x.x.Portable.exe` من [صفحة الإصدارات](https://github.com/SMSMy/mas-activator-Disktop/releases)
2. انقر بالزر الأيمن ← **تشغيل كمسؤول** ثم وافق على طلب UAC
3. لا تثبيت ولا بقايا — احذف الملف عند الانتهاء

> 📌 **متطلب النسخة المحمولة:** WebView2 Runtime (موجود افتراضيًا في أي Windows 10/11 محدّث). إن لم تعمل النسخة المحمولة على نظامك القديم، استخدم المثبّت.

### المثبّت (بديل)
`MAS.Activator_x.x.x.Setup.exe` — لأجهزة تفتقد WebView2 أو لمن يفضّل تثبيتًا دائمًا مع اختصارات قائمة ابدأ.

> ⚠️ **مهم:** يتطلب البرنامج صلاحيات المسؤول لتنفيذ عمليات التفعيل والتغيير.

## 🔧 طرق التفعيل المتاحة

### 🪟 تفعيل ويندوز — HWID
التفعيل الرقمي المرتبط بعتاد الجهاز. **دائم** ولا يحتاج اتصالاً بعد التفعيل.
- يدعم: Windows 10 / 11 جميع الإصدارات

### 📄 تفعيل أوفيس — Ohook
يثبت hook على خدمة ترخيص Office. **دائم** ويعمل بدون اتصال.
- يدعم: Office 2016, 2019, 2021, 2024, 365

### 🛡️ TSforge
طريقة متقدمة تدعم:
- Windows 10/11 ESU (التحديثات الممتدة)
- إصدارات Windows Server
- Office بجميع إصداراته

### 🌐 Online KMS
- يحتاج اتصالاً بالإنترنت
- التفعيل يستمر 180 يوماً ويتجدد تلقائياً

> 🔒 جميع الطرق تنفَّذ من سكربت MAS **محلي مُتحقق منه** (SHA-256) — يتم تنزيله مرة واحدة ويُعاد التحقق من سلامته في كل تشغيل.

## 🔁 تغيير إصدار ويندوز

يتيح التطبيق التحويل بين إصدارات Windows المدعومة (مثل Home → Pro) من واجهة داخلية:

1. يعرض الإصدار الحالي والوجهات **المدعومة من النظام فقط** (المسارات المحجوبة لا تظهر)
2. ينفَّذ التحويل عبر أدوات Windows الرسمية (`changepk` / `slmgr` / `DISM`) بمفتاح الإصدار **العام** الذي يسترجعه من النظام نفسه وقت التشغيل — **لا يُدخل التطبيق مفتاحك الشخصي ولا يخزّنه**
3. يعرض النتيجة بصدق بثلاث طبقات: هل المسار مدعوم؟ هل تغيّر الإصدار فعلاً؟ وهل هو مفعل؟

> ⚠️ تغيير الإصدار ≠ التفعيل، وقد يتطلب إعادة تشغيل. استخدم ميزة «فتح إعدادات تنشيط Windows» لإدخال مفتاحك الشخصي الرسمي بنفسك.

## 🔍 فحص الحالة

يعرض البرنامج تقريراً دقيقاً يشمل:

| الكود | المعنى |
|-------|--------|
| ✅ مفعل | الترخيص صالح ونشط |
| ⚠️ إشعار ترخيص | يحتاج مراجعة (Notification) |
| ⏳ فترة سماح | ضمن مهلة Grace Period |
| ❌ غير مرخص | يحتاج تفعيلاً |
| ❌ نسخة غير أصلية | اكتُشف انتهاك للترخيص |

## 🛡️ ملاحظة عن حماية النظام

قد تعترض حماية النظام (Windows Security / مضادات الفيروسات) أدوات التفعيل مفتوحة المصدر. إن حدث اعتراض فسترى رسالة واضحة وزرًا يفتح إعدادات حماية Windows. **أي تغيير في إعدادات الحماية قرارك ومسؤوليتك — أعد التمكين فور انتهاء العملية.**
